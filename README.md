## 📌 Technical Overview

**CampPrepper** is a responsive outdoor equipment and camping trip preparation manager. It enables campers and hikers to organize packing lists across categories (Shelter, Cooking, Navigation, First Aid), toggle item preparation states, and persist checklist data across browser sessions.

---

## ✨ Key Features

- **Categorized Gear Ledger**: Organize camping essentials across custom equipment groups.
- **Dynamic Packing Status**: Real-time progress indicators showing packed vs pending gear.
- **Persistent Local State**: Automatically synchronizes checklist items with browser `localStorage`.
- **Responsive Layout**: Designed for seamless mobile and desktop use at campsite or home.
